# Disc coverage: what is decoded

> Generated by `tools/src/cli/coverage.ts` on 2026-10-15 with SLES-53559. **Do not edit by hand**: change the script's
> `FILE_RULES` / `CHUNK_RULES` tables and run `bun src/cli/coverage.ts <iso> <ID> --docs` again.
> Tags: [V] verified on bytes · [D] decomp · [I] inferred · [H] hypothesis.

How it is counted:
- Every `NFS/ZDIR.BIN` file is classified by its path. Files with bChunks (`.BUN`, `.BIN`, `.LZC`) are walked chunk by
  chunk (`.LZC` decompressed first) and their disc bytes are split among chunk IDs proportionally.
- Statuses: **decoded + used** (a reader exists in `tools/src/lib` and the port uses it) · **decoded, unused** (we can read it,
  the native game does not use it yet) · **partial** · **unknown** (name known from the decomp, format not).
- "Before" = status when the audit started (2026-10-15); "now" = after this batch of decoding.
- Repeated bytes (ZDIR points several times at the same place) are counted once. The ELF, IOP modules and the
  `ZZDATA*.BIN` padding are counted too.

## Notes

- Movies are 59 % of the disc: that is why the "understood" percentage is high even though small formats remain.
  What really remains is in the last table, sorted by size.
- Findings of this audit: the 64 `_UNKNOWN` video entries are `MOVIES\*_SPANISH_PAL.MPC` and `*_ITALIAN_PAL.MPC`
  (the story is **dubbed** in Spanish and Italian); the `*MEMORYFILE.BIN` files are bundles of copies of other files;
  subtitles live in `LANGUAGES\<LANG>.BIN` (doc 22).
- Added names: `tools/data/filenames-extra.list`.
- "Decoded" measures the **format**: we can read every byte and know what it is. It does not mean the native game uses it yet:
  used is still 23 %. What remains to be used (movies, music, NIS scenes, particles, game collision…) is in docs 22–25.
- Details still open inside "decoded": EAGL animation type 17 (DeltaQ, a single animation), NIS character skin weights,
  meaning of 7 music actions, names of 226 world objects (docs 22–25).
